# Jaaxis CLI

The command-line tool for working on your Jaaxis agents, by hand or from a coding agent such as Claude Code or Codex.

## Install

macOS and Linux:

```bash
curl -fsSL https://github.com/Jaaxis/jaaxis-cli/releases/latest/download/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://github.com/Jaaxis/jaaxis-cli/releases/latest/download/install.ps1 | iex
```

Every release is signed; the installer checks the signature and installs nothing if it fails. The CLI keeps itself up to date.

## Get started

```bash
jaaxis login
jaaxis help
```

`jaaxis help <command>` explains any command.
